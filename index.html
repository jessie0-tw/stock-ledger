雲端即時同步說明
本帳本已支援 **Firebase Firestore** 雲端即時同步。開通後，各個裝置（電腦與手機）只要開啟網址，無須輸入任何金鑰即會自動同步更新。

設定步驟：
1. 登入 Firebase Console，建立一個免費的專案。
2. 在該專案中建立一個 **Firestore Database** 資料庫（建議選擇測試模式以開放讀寫）。
3. 新增一個「Web 網頁應用程式」，並複製出現的 firebaseConfig（包含 apiKey、projectId 等欄位）。
4. 打開本機的 index.html 檔案，在程式碼最上方的 firebaseConfig 物件中填入對應欄位，並設定一個自訂的 SYNC_CODE 作為同步密碼。
5. 儲存並將 index.html 上傳至 GitHub Pages，即可完成跨裝置無縫同步！
